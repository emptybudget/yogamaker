# 요가메이커 (yogamaker) — 기획 & 개발 계획

요가 강사가 **폰에서 빠르게 시퀀스를 짜고**, **아이패드로 수업 중에 띄워 보는** 웹앱.

---

## 1. 형식: PWA (설치형 웹앱)

- 브라우저에서 열리고, 홈 화면에 추가하면 앱처럼 동작 (iPhone / iPad / Android / PC 모두)
- 오프라인 동작 (요가원 와이파이 약해도 OK)
- 정적 사이트라 배포 무료 (Vercel 권장 — PR마다 미리보기 링크가 생겨서 Codex 작업 확인이 쉬움)

**스택**: Vite + React + TypeScript + Tailwind CSS
- 드래그 정렬: `@dnd-kit`
- 로컬 저장: IndexedDB (`dexie`)
- PWA: `vite-plugin-pwa`
- 테스트: `vitest`

## 2. 기존 시퀀스 노트에서 발견한 패턴 (반드시 지원)

친구가 지금까지 짠 시퀀스 44장(굿노트 손글씨 + 한글 표 문서)을 분석한 결과:

| 패턴 | 실제 예시 | 앱에서 |
|---|---|---|
| **3단 표 구조**: 섹션 / 동작 목록 / 큐잉 멘트 | 거의 모든 문서 | 편집 화면·인쇄 모두 이 구조 유지 |
| **수업 헤더** | `0908 서울역`, `힐링빈야사 50분 – 앞면, 옆면 열어내는`, `웜업 10 – 수리야 10 – 메인 10/10 – 쿨다운 10` | 날짜·장소·수업유형·주제·총시간 |
| **호흡 / 횟수 / 카운트** | `숨5`, `홀딩5`, `x3`, `5회`, `5카운트 홀딩` | 타이밍 = 호흡 수 / 초 / 반복 횟수 |
| **좌우** | `R/L`, `반대쪽 동일`, `>반대`, `양쪽` | 좌우 토글 → 시간 자동 2배 |
| **세트(블록)** | `Set A / Set B`, `#1 #2 #3`, `2번 해서 방향전환` | 포즈 묶음 + 반복 횟수 + 양측 |
| **수리야 약식 표기** | `수리야 A3, R2, A1, R1`, `전사 A2 B2 R1`, `ABR 빠르게` | 수리야 블록 (A/B/R 횟수 입력) |
| **연결 동작(플로우)** | `다운독 – 워킹다운독 x5`, `플랭크 차투랑가 업독 다운독` | 한 줄에 여러 포즈 이어 붙이기, "빈야사" 연결 아이템 |
| **선택 동작** | `시간없으면 생략` | "생략 가능" 표시 (시간 합계에서 별도 표시) |
| **구어체 포즈명** | 다운독, 하이런지, 소고양이, 버드독, 우르드바, 사바(SAVA), 아르다하누만 | 한글 별칭 검색 필수, 산스크리트명은 보조 |
| **섹션 이름 유연함** | 웜업/네발/본동작/수리야/쿨다운, 바즈라, 고관절 | 기본 5섹션 + 섹션 추가·이름 변경 가능 |
| **손그림 졸라맨** | 굿노트 스케치 | 3차: 포즈별 간단한 스케치/아이콘 (선택) |

## 3. 기본 시퀀스 구조 & 시간 규칙

| 섹션 | 목표 |
|---|---|
| 웜업 | 10분 |
| 네발토대 | 10분 |
| 두발토대 | ┐ 합쳐서 15–20분 |
| 피크포즈 | ┘ |
| 쿨다운 | 5–10분 |
| **합계** | **40–50분** |

- 목표는 "범위(min–max)"로 저장하고, **두발토대+피크처럼 여러 섹션을 묶은 목표**도 지원
- 섹션 옆에 `8:30 / 10분` 처럼 표시, 범위 밖이면 색으로 경고 (부족=노랑, 초과=빨강)
- 템플릿마다 목표 변경 가능 (예: 힐링 50분, 오픈클래스 60분)

### 시간 계산 (분·초 + 호흡 둘 다)
- 타이밍 종류: `seconds` (초) / `breaths` (호흡 수) / `reps` (반복 횟수)
- 호흡 1회 = 시퀀스 설정값 (기본 **5초**, 수업마다 조절 — 힐링은 6초, 빈야사는 4초 등)
- 반복 1회 = 기본 호흡 1회로 계산 (포즈별로 조절 가능)
- 좌우(R/L) = ×2, 세트 반복 = ×n, 전환 시간 = 포즈당 기본 5초 (설정 가능)
- 화면에는 입력한 단위 그대로 보여주고(`숨5`), 합계만 분:초로 환산

## 4. 데이터 구조 (초안)

```ts
type Timing =
  | { kind: 'seconds'; value: number }
  | { kind: 'breaths'; value: number }
  | { kind: 'reps'; value: number; secPerRep?: number };

type Pose = {
  id: string;
  name: string;            // 대표 이름 (예: "다운독")
  aliases: string[];       // ["아도무카스바나사나", "downward dog", "다운독"]
  sanskrit?: string;
  category: 'warmup' | 'quadruped' | 'standing' | 'peak' | 'cooldown' | 'transition';
  defaultTiming: Timing;
  sided: boolean;          // 기본적으로 좌우가 있는 동작인지
  defaultCue?: string;     // 자주 쓰는 큐잉 멘트
};

type Step = {
  type: 'pose';
  id: string;
  poseId?: string;         // 라이브러리 포즈
  label: string;           // 자유 입력도 허용 ("팔꿈치 내려놓고 왼팔 귀옆")
  timing: Timing;
  sides: 'none' | 'RL';
  optional?: boolean;      // 시간없으면 생략
  cue?: string;            // 큐잉 멘트 (긴 글)
  note?: string;
};

type Block = {
  type: 'block';           // Set A, #1, 수리야 등
  id: string;
  label: string;
  repeat: number;
  sides: 'none' | 'RL';    // "반대쪽 동일"
  items: Step[];
};

type Section = {
  id: string;
  name: string;            // "웜업"
  kind: 'warmup' | 'quadruped' | 'standing' | 'peak' | 'cooldown' | 'custom';
  items: (Step | Block)[];
};

type Sequence = {
  id: string;
  title: string;           // "힐링빈야사 – 앞면, 옆면 열어내는"
  classType?: string;      // 힐링 / 빈야사 / 하타플로우 / 스트레칭 테라피
  date?: string;
  location?: string;       // 방이 / 서울역 / 구리
  theme?: string;
  secPerBreath: number;
  targets: { sectionIds: string[]; minMin: number; maxMin: number }[];
  sections: Section[];
  createdAt: string;
  updatedAt: string;
};
```

## 5. 화면 구성

### A. 시퀀스 목록 (홈)
- 카드: 제목, 날짜·장소, 총시간, 수업유형 태그
- 검색 / 유형 필터 / 복제 / "템플릿으로 새로 만들기"

### B. 편집기 (폰 우선)
- 섹션별 접이식 카드, 섹션 헤더에 시간 바 (목표 대비)
- **빠른 입력** ★ 핵심: 노트에 쓰듯 한 줄 입력 → 자동 해석
  - `다운독 숨5` → 다운독, 호흡 5
  - `버드독 접었다폈다 5회 R/L` → 반복 5, 좌우
  - `다운독 – 워킹다운독 x5` → 두 포즈 연속
  - `수리야 A2 B2 R1` → 수리야 블록
  - 입력 중 포즈 자동완성 (별칭 검색)
- 길게 눌러 드래그로 순서 변경, 스와이프로 삭제/복제
- 포즈 탭 → 상세 시트(타이밍, 좌우, 생략가능, 큐잉 멘트)
- 블록 만들기: 여러 포즈 선택 → "세트로 묶기"

### C. 수업 모드 (아이패드 가로 화면 최적화)
- 큰 글씨: 현재 포즈 + 남은 호흡/시간, 좌/우 표시, 큐잉 멘트
- 옆에 다음 포즈 2–3개, 상단에 섹션 진행 바 & 전체 경과/남은 시간
- **기본은 수동 넘김**(탭/스와이프) + 경과 시간 표시 — 실제 수업은 강사 페이스대로 흘러가므로
- 자동 넘김 모드(선택), 섹션 전환 시 부드러운 알림음(선택)
- 화면 꺼짐 방지 (Screen Wake Lock API)
- 다크 모드 (어두운 수업 공간)

### D. 포즈 라이브러리
- 기본 포즈 80–120개 (기존 노트에서 추출한 친구의 실제 용어로 시드)
- 포즈 추가/수정, 자주 쓰는 큐잉 멘트 저장

### E. 인쇄 / PDF
- 지금 쓰는 **3단 표 형식** 그대로 (섹션 / 동작 / 큐잉)

## 6. 폰 ↔ 아이패드 옮기기

폰에서 짜고 아이패드에서 띄우려면 기기 간 이동이 필요하다.

- **1차 (서버 없음)**: 공유 링크 / QR 코드 — 시퀀스를 압축해서 URL에 담음 (`lz-string`). 아이패드로 QR 찍으면 바로 열림. + JSON 파일 내보내기/가져오기 (백업용)
- **2차**: 로그인 + 클라우드 동기화 (Supabase). 모든 기기 자동 동기화

## 8. 성공 기준

- 폰에서 50분 수업 시퀀스를 **10분 안에** 짤 수 있다
- 섹션별 시간이 목표 안에 들어오는지 한눈에 보인다
- 아이패드에서 수업 중 2m 거리에서도 현재/다음 포즈가 읽힌다
- 인터넷 없이도 열린다
